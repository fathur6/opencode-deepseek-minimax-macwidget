## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Keychain → resolver | Encrypted provider secrets are returned only to a caller that will authenticate the selected provider request. |
| Legacy auth.json → resolver | User-owned historical credentials are read as a compatibility fallback and must remain immutable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03 | Information Disclosure | Keychain adapter and resolver | high | mitigate | Use generic-password Keychain storage, return values only to resolver callers, and test that synthetic values do not enter defaults/cache fixtures or diagnostics. |
| T-05-04 | Tampering | legacy auth.json | high | mitigate | Resolver has read-only narrow access; fixture byte equality proves resolution/removal leave the source unchanged. |
| T-05-05 | Denial of Service | Security calls | medium | mitigate | Run blocking Security calls on a non-MainActor/background path and return redacted failure categories. |
| T-05-SC | Tampering | package installation | low | accept | No npm, pip, cargo, or third-party package installation is planned. |
</threat_model>

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical Functionality] Added a real cache location for the menu-only app**
- **Found during:** Task 3 live deployment verification
- **Issue:** The configured app-group container was unavailable because the app has no app-group entitlement, so refreshed history could not be persisted.
- **Fix:** Route the default cache to `~/Library/Application Support/OpencodeWidgetApp/widget-data.json` while retaining explicit-path and non-default group behavior.
- **Files modified:** `DataStore.swift`, `DataStoreTests.swift`
- **Verification:** Live deployed app wrote 168 history buckets to the cache.

**2. [Rule 3 - Blocking Generated Output] Ignored explicit Xcode derived data**
- **Found during:** Task 3 build
- **Issue:** The required `-derivedDataPath build` output appeared as untracked generated content.
- **Fix:** Added `opencode-widget/build/` to `.gitignore`.

**3. [Rule 1 - Accounting Bug] Corrected Codex cached-token handling**
- **Found during:** Independent post-execution diff review
- **Issue:** Codex `input_tokens` already includes cached input, so adding cached detail fields counted those tokens twice. Mixed last/cumulative events could also leave the cumulative baseline stale.
- **Fix:** Count Codex `input_tokens` once and advance the cumulative baseline whenever total usage accompanies a last-usage event.
- **Files modified:** `UsageHistoryFetcher.swift`, `UsageHistoryFetcherTests.swift`
- **Verification:** Full 121-test suite and Xcode Release build passed again; corrected binary was redeployed and hash-matched.

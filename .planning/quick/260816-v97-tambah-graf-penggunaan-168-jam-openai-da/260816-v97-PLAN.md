Filter `billing_provider IN ('openai-codex','deepseek')`; count cumulative `input_tokens + cache_read_tokens + cache_write_tokens` and attribute each current row to `last_seen` epoch seconds. - Codex history is under both `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` and `~/.codex/archived_sessions`. Parse only `event_msg` records whose payload type is `token_count`. Prefer `info.last_token_usage`; when it is absent, derive a non-negative delta from successive `info.total_token_usage` values within that file. Count input, cached input, and cache-write input fields and attribute the event to its ISO-8601 `timestamp`.
- Swift Charts is available on the macOS 14 deployment target; no package install is needed.

| Codex JSONL filesystem → parser | Potentially large or malformed local session records cross into incremental decoding. |
| Build output → `/Applications`/LaunchAgent | A locally built executable replaces the installed menu-bar app and is launched persistently. |

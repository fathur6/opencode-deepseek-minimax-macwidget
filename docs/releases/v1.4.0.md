# v1.4.0 — OpenAI on its own hidden y-axis in the Usage chart

## Highlights

- The **Usage** chart no longer squashes OpenAI into invisibility. DeepSeek
  still drives the visible leading y-axis (its own zero-based auto-max, labelled
  in tokens), while OpenAI is drawn on a **hidden second y-axis with its own
  zero-based auto-max**.
- OpenAI's peak now reaches the top of the plot and its shape stays
  proportional to its own maximum, so small OpenAI token usage is readable next
  to multi-million-token DeepSeek spikes.
- Point accessibility values still report each provider's real token count; only
  the plotted height is normalised for the hidden axis.

## Behaviour details

- `UsageHistoryChartProjection` now exposes `deepseekMaxTokens` and
  `openAIMaxTokens` and stores both the real `tokens` and the display
  `plotTokens` per point.
- OpenAI `plotTokens = tokens / openAIMax × deepseekMax`, keeping the green line
  inside the visible DeepSeek domain without altering its silhouette.
- Empty, all-zero, single-bucket and non-finite inputs are clamped to a finite
  non-zero domain (no NaN, no division by zero). If OpenAI is all zero the line
  simply sits on the baseline.

## Caveats

- The hidden OpenAI axis means the green line's height is relative to OpenAI's
  own maximum, not the visible token labels. This is intentional so the small
  series stays legible.
- The DMG is ad-hoc signed, not notarized.
